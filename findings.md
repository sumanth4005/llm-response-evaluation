# Findings and Recommendations

## Project Summary
This project compares responses from ChatGPT, Gemini, and Claude using the same set of questions.

Each response was evaluated based on:
- Accuracy
- Relevance
- Completeness
- Tone
- Hallucination Risk
- Overall Score

## Key Findings
- All three models generally produced relevant and understandable responses.
- Response quality varied depending on the type and complexity of the question.
- Some models were more concise, while others provided more detailed explanations.
- Hallucination risk was lower for general conceptual questions and higher when the model needed to make assumptions.
- Consistent evaluation criteria helped make the model comparison more structured.

## Product Insights
- LLM performance should not be measured using only one metric.
- Accuracy, relevance, completeness, tone, and hallucination risk should be reviewed together.
- Human review is important for sensitive or high-risk AI use cases.
- Prompt design can significantly affect response quality.

## Recommendations
- Use standardized prompts when comparing models.
- Add human review for high-risk outputs.
- Expand testing to more question categories.
- Continue monitoring hallucination patterns.
- Use dashboards to track model quality over time.

## Future Improvements
- Test additional LLMs.
- Increase the number of evaluation questions.
- Add category-level analysis.
- Create Power BI dashboards.
- Track model response consistency over multiple runs.
