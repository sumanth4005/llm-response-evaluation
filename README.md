# LLM Response Evaluation

## Project Overview
This project compares responses from multiple Generative AI tools to evaluate differences in quality, accuracy, relevance, completeness, tone, and hallucination risk.

## Models Evaluated
- ChatGPT
- Gemini
- Claude

## Project Goal
The goal of this project is to understand how different large language models respond to the same questions and identify strengths, weaknesses, and possible risks in their outputs.

## My Role
- LLM Evaluation
- Prompt Design
- AI Product Analysis
- Quality Assessment
- Response Comparison
- Product Recommendations

## Evaluation Metrics
Each response is evaluated using the following criteria:

- Accuracy
- Relevance
- Completeness
- Tone
- Hallucination Risk
- Overall Response Quality

## Project Process
1. Create a set of evaluation questions.
2. Ask the same questions to multiple AI models.
3. Record the responses.
4. Score each response using consistent evaluation criteria.
5. Compare the performance of the models.
6. Identify strengths and weaknesses.
7. Document findings and recommendations.
